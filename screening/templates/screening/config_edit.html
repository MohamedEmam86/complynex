Weight Distribution

The sum of name matching weights ideally should be around 1.0 for predictable behavior, although the engine handles any sum.

Fuzzy vs Jaro-Winkler

JW is generally superior for names due to prefix matching. Fuzzy (Levenshtein) is better for identifying common OCR or spelling errors deep in the string.

Auto-Match Threshold

Setting this to 0.95+ ensures only near-exact matches are automatically blocked. Lowering it reduces manual review but increases false positives.
